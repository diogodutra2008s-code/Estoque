# Sistema de Estoque

Sistema desenvolvido em JavaScript para controle de produtos e estoque.

## Funcionalidades

- Cadastro de produtos
- Consulta de produtos
- Controle de estoque
- Registro de vendas
- Relatório de produtos

## Tecnologias

- JavaScript
- Node.js

## Como executar

1. Clone o repositório
2. Instale as dependências
3. Execute o projeto
